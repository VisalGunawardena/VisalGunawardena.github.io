# Visal Gunawardena — portfolio

Mechanical engineer, University of Moratuwa. Live site: https://visalgunawardena.github.io

Static site: `index.html` plus `assets/` (3D models, photos, video) and `live/` (interactive BundLink, Niyara and Shear Force demos).
Three.js, GSAP, Lenis and Matter.js load from public CDNs. To run locally: `python -m http.server` in this folder, then open http://localhost:8000.
